# **地心冒險 (Underground Adventure)**

**《地心冒險》** 是一款 2D 橫向卷軸動作遊戲，玩家將探索地心世界，挑戰各種機關與敵人，並支援 **單人模式** 和 **多人連線模式**。

---

## **🎮 遊戲玩法**

### **單人模式**
- 玩家控制角色在地心世界中冒險，挑戰不同的關卡與機關。
- 角色可進行 **移動、跳躍、攻擊、躲避陷阱**。
- 下樓梯與多人射擊。

### **多人模式 (Photon PUN)**
- 透過 **Photon PUN** 技術，支援 **多人即時連線**。
- 玩家可以與好友一起挑戰地心世界，合作通關。
- 採用 **RPC（Remote Procedure Call）技術**，確保多人連線時動作同步。

---

## **🛠️ 使用技術**
- **遊戲引擎**: Unity 2D
- **多人連線**: Photon PUN
- **開發語言**: C#
- **網路同步技術**: RPC（Remote Procedure Call）
- **物理引擎**: Unity Physics 2D
- **動畫**: Unity Animator
- **音效處理**: Unity Audio Mixer

---

## **🚀 開發難點與解決方案**

### **1. RPC 同步問題**
- 透過 **Photon PUN** 來確保不同玩家之間的狀態同步。
- 運用 **PhotonView** 和 **RPC 呼叫**，讓角色動作在所有玩家端都一致。

### **2. 物理碰撞與陷阱機制**
- 運用 Unity 內建的 **2D 碰撞系統**，確保角色能夠正確地與機關、敵人互動。
- 使用 **Raycast** 技術偵測角色與地面、障礙物的碰撞，避免角色穿牆或卡住。

### **3. 多人連線的延遲與資料同步**
- 透過 **Photon Transform View** 來優化移動同步。
- 利用 **Interpolation（插值）與 Extrapolation（預測）** 降低玩家之間的延遲感。
